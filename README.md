# עוזר נושא ל-Canva (גרסה ראשונית להרצה מקומית)

אפליקציית Canva שנפתחת בפאנל הצדדי של העורך. המורה בוחרת תחום, נושא וכיתה, ולוחצת על הצעות שמוסיפות לעיצוב עמודים וטקסט בעברית. התוכן כרגע מספרייה קבועה לשני נושאים ("מחזור המים" ו"חלקי הצמח") בקובץ `src/library.ts`. בהמשך התוכן ייווצר על ידי LLM.

הגרסה הזו רק לבדיקה על המחשב שלך. היא לא נשלחת ל-Canva לביקורת.

## הרצה על המחשב

דרוש Node.js בגרסה 22 ומעלה.

```bash
npm install
npm start
```

השרת המקומי עולה בכתובת http://localhost:8080 (זה לא דף שמיועד לפתיחה בדפדפן, אלא כתובת ש-Canva טוענת ממנה את האפליקציה).

## חיבור לעורך האמיתי של Canva

עושים את זה פעם אחת. ממשק ה-Developer Portal משתנה, ולכן ייתכן שהשמות קצת שונים:

1. נכנסים ל-https://www.canva.com/developers/apps ויוצרים אפליקציה חדשה. בבחירת קהל היעד בוחרים "Anyone on Canva" (האפשרות "Restricted to your Canva team" דורשת חשבון Enterprise ואי אפשר לשנות את הבחירה אחר כך). אין צורך להגיש את האפליקציה לביקורת.
2. באפליקציה, בעמוד "Inside Canva" (או "Design Editor"), בקטע Code upload, בשדה **App source** בוחרים **Development URL** וממלאים `http://localhost:8080`.
3. מעתיקים את ה-App ID לקובץ `.env` בשדה `CANVA_APP_ID` (הקובץ נוצר אוטומטית ב-`npm install`), או מריצים `npx @canva/cli apps link`.
4. מריצים `npm start`. לוחצים Preview בפורטל, או מריצים `npm run start:preview`, וזה פותח עיצוב חדש של Canva עם האפליקציה.
5. Chrome עשוי לבקש הרשאה לגשת לרשת המקומית. מאשרים.

אחרי שינוי בקוד סוגרים ופותחים שוב את האפליקציה בעורך (או מפעילים `CANVA_HMR_ENABLED=TRUE` ב-`.env` ומגדירים את `CANVA_APP_ORIGIN` לפי ההגדרות בפורטל).

## מה כדאי לבדוק קודם

- אם טקסט בעברית שנוסף לעיצוב מוצג מימין לשמאל ובצורה נכונה.
- באיזה צד של העורך הפאנל מופיע.
- האם "עמודים מוכנים" מוסיפים עמוד חדש עם כותרת וטקסט (העמוד מותאם לגודל של מצגת רגילה, 1920×1080).

## מבנה

- `src/library.ts` ספריית התוכן.
- `src/intents/design_editor/app.tsx` הפאנל.
- `.env.template` תבנית להגדרות מקומיות.
